# AI Based Online Examination System — Simple UI Update

## Product name

- The user-facing product name is now **AI Based Online Examination System**.
- Public pages, role portals, emails, PDFs, monitoring evidence labels, configuration text and documentation use the new name.
- Existing reusable demo exam data is reused and renamed instead of creating a duplicate record.

## Interface

- Public, Admin, Teacher and Student layouts now share a clean navy, blue and white design.
- Large decorative headings, heavy gradients, excessive shadows and pill-shaped action buttons were reduced.
- Cards, forms, tables, menus, page spacing and mobile layouts use consistent sizes and clearer contrast.
- Public Home, About, How It Works, Features, Common Questions, Help and Privacy pages use shorter, direct language.
- High-visibility dashboard labels and instructions were rewritten in simple task-focused language.

## Registration

- Removed the expandable **Add optional candidate details now** section and its plus button.
- Registration now contains four clear steps: account type, basic information, current photo and password.
- Additional profile information can be completed after sign-in.

## Additional consistency fixes

- Added Teacher portal links to the public signed-in navigation and shared account menu.
- Updated sign-in, password reset, access denied, sign-out, error and status pages.
- Added the Teacher dashboard option to status/error navigation.
- The later AI reset intentionally removed the legacy proctoring models while preserving exam, result and account functionality.
